# Day01 - 进程与线程

## 进程

### 虚拟地址空间
- 对于 32 位操作系统, 最多可以给进程分配 **2^32 (4GB) 的虚拟地址空间**
- 虚拟地址空间分为两部分:
  - **用户态空间** (一般占 3GB 左右): 用户程序可访问
  - **内核态空间** (一般占 1GB 左右): 只有内核可访问, 用户程序必须通过系统调用进入
- 每个进程都拥有自己独立的虚拟地址空间 (注意是**虚拟**的, 物理内存由操作系统统一管理)

### 进程的定义
- **程序运行起来之后就称为进程**
- 进程是 **资源分配的基本单位** (CPU、内存、文件等资源以进程为单位分配)
- 进程与进程之间是 **隔离** 的: 一个进程崩溃不影响其他进程, 一个进程不能直接访问另一个进程的内存

### 进程的特点
- 独立性: 每个进程有独立的地址空间、PCB (task_struct)
- 进程切换开销很大: 切换地址空间、保存/恢复上下文、刷新缓存等

## 线程

### 线程的定义
- **线程是轻量级的进程** (Lightweight Process)
- 一个进程中**至少包含一个线程**, 这个线程就是 main 函数所在的主线程
- **线程是程序调度的基本单位** (CPU 调度的是线程)

### 线程与进程的对比
| | 进程 | 线程 |
|---|---|---|
| 划分依据 | 资源分配的基本单位 | 程序调度的基本单位 |
| 地址空间 | 独立 (隔离) | 同一进程内共享地址空间 |
| 资源 | 各持一份 | 共享进程资源 |
| 栈 | 独立栈空间 | **每个线程也有自己独立的栈空间** |
| 切换开销 | 大 | 比进程小很多 (不需要切换地址空间) |
| 关系 | 一个进程可含多个线程 | 线程是进程的子单位 |

### 线程的资源共享
- 一个进程包含多个线程, 则多个线程**共享进程的资源**, 这些资源包括:
  - 全局变量/静态变量
  - 堆内存 (动态分配的内存)
  - 打开的文件描述符/文件
  - 进程的代码段 (函数定义)
  - 信号处理函数等
- **为了区分不同的线程**, 每个线程都有自己的**独立的栈空间** (栈存放局部变量、函数调用信息)

### pthread_create: 创建线程
```c
#include <pthread.h>
int pthread_create(pthread_t *thread, const pthread_attr_t *attr,
                   void *(*start_routine)(void *), void *arg);
```
- **thread**: 传出参数, 保存新线程的线程 ID, 类型是 `pthread_t` (注意: 这是**线程 ID** 的类型, 不是进程 ID)
- **attr**: 线程属性, 默认属性设置为 NULL
- **start_routine**: 函数指针 -- 这个函数指针指向的函数叫做**线程的入口函数**, 线程需要执行的所有操作都从该函数开始, 也都在该函数中完成
- **arg**: 给线程入口函数传递的参数, 传递后自动传入入口函数; 不需要参数时可使用 NULL
- 返回值: 成功返回 0; 失败返回错误码

```c
void *thread_func(void *arg) {
    printf("thread arg = %s\n", (char *)arg);
    return NULL;
}

int main(void) {
    pthread_t tid;
    int ret = pthread_create(&tid, NULL, thread_func, "hello");
    if (ret != 0) {
        fprintf(stderr, "pthread_create error\n");
        exit(1);
    }
    pthread_join(tid, NULL);   // 等待线程结束
    return 0;
}
```
- 编译注意: 使用 pthread 需要加 `-lpthread` 链接选项

### 复习: 指针家族
- **指针数组**: 数组, 每个元素是指针, 如 `char *arr[4]`
- **数组指针**: 指向数组的指针, 如 `int (*p)[4]`
- **函数指针**: 指向函数的指针, 如 `int (*fp)(int, int)` (pthread_create 的 start_routine 就是函数指针)
- **指针函数**: 返回值为指针的函数, 如 `int *func(void)`

## 练习

1. 打印进程和线程编号: 用 getpid() 和 pthread_self() 对比主线程
2. 写两个线程: 一个打印全局变量, 一个修改全局变量, 观察共享
3. 每个线程里声明局部变量, 打印其地址, 观察线程独立栈空间
4. pthread_create 传两个参数: 把结构体指针作为 arg 传入线程入口函数
5. 主线程用 pthread_join 等待子线程结束, 观察等待与不等待的差异
